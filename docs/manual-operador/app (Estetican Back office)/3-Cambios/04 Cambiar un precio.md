# 04 Cambiar un precio

**Para qué sirve:** subir o bajar el precio de un servicio.

**Antes de empezar:** el servicio ya existe ([[06 Servicios y precios]]).

**Dónde está:** **Catálogos → Servicios**.

## Pasos
1. En **Catálogos → Servicios**, busca el servicio y toca **Editar**.
2. Cambia el **Precio sugerido**.
3. Si cambió el tiempo que lleva, ajusta también la **Duración sugerida (min)**.
4. Toca **Actualizar servicio**.

Para un artículo, es igual en **Operaciones del negocio → Inventario → Artículos** → **Editar** → **Precio de venta** ([[11 Artículos y stock]]).

## Efecto en el mob
- Las citas **nuevas** del celular ya salen con el precio nuevo ([[04 Servicio y precio]]).
- Las citas **ya agendadas** se quedan con el precio que tenían. Si quieres cobrarles el nuevo, el operador lo cambia al cobrar ([[10 Cobrar y entregar]]).
- Las **citas recurrentes** ya creadas conservan el precio con el que se creó la serie.

## Qué vas a ver
- El precio nuevo en la lista de servicios.

## Si algo sale mal
| Lo que ves | Qué hacer |
|---|---|
| El operador todavía ve el precio viejo | Que cierre y vuelva a abrir **Nueva cita** en el celular. |
| No ves **Editar** | Si no ves esta opción, tu usuario no tiene acceso; pídelo al administrador principal. |
